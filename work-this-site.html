// 概要

プロジェクト概要

このポートフォリオサイトは、AIのコーディングツール「Claude Code」と一緒に作りました。HTML・CSS・JavaScriptのコードの多くはAIが書いています。私は、サイトで紹介している作品の制作と、変更をブラウザで1つずつ確認して修正を指示すること、Git / GitHubでの管理・公開を担当しました。

// 役割分担

役割分担

01

私 — 作品をつくる

サイトで紹介しているポスター・ZINE・Figmaでのデザインなどの作品を制作する。

02

AI（Claude Code） — コードを書く

依頼に合わせて、HTML・CSS・JavaScriptのコードを書き、修正する。

03

私 — 確認と修正の指示

変更をブラウザで確認し、気になるところはスクリーンショットを送って、直るまで修正を指示する。

04

私 — Git / GitHubで管理・公開

変更をGitHubに同期し、GitHub Pagesでサイトを公開する。

// 主な機能

主な機能

01

日本語 / 英語の切り替え

ヘッダーの「EN / JP」で、サイト全体の言語を切り替えられます。

02

最初の1回だけのオープニング

サイトに入ったときだけ、ロゴのアニメーションが流れます。

03

逆向きに動くスクロールギャラリー

作品一覧の「すべて」では、まん中の列と左右の列が逆向きに動きます（PCのみ）。

04

めくれる3DのZINE

ZINEの作品ページでは、本のようにページをめくって読めます。

05

お問い合わせフォーム

フォームから送ったメッセージが、メールで届きます（Formspree）。

自分で書いたコード
